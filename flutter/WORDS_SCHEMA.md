# Words Database Schema

This document describes the database schema for storing Hangman game words, tags, and their relationships in Supabase.

## Tables

### 1. `public.words`

Stores words for the Hangman game with difficulty values and locale information.

```sql
CREATE TABLE public.words (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  word TEXT NOT NULL,
  difficulty_value INTEGER NOT NULL CHECK (difficulty_value >= 1 AND difficulty_value <= 100),
  locale TEXT NOT NULL DEFAULT 'en',
  created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
  CONSTRAINT words_word_locale_unique UNIQUE (word, locale)
);
```

**Fields:**
- `id`: Auto-incrementing primary key
- `word`: The word to be guessed (unique per locale)
- `difficulty_value`: Numeric difficulty from 1 (easiest) to 100 (hardest)
  - Easy: 1-33
  - Medium: 34-66
  - Hard: 67-100
- `locale`: Language code (e.g., 'en', 'es')
- `created_at`: Timestamp when the word was added

### 2. `public.tags`

Stores descriptive tags/hints for words.

```sql
CREATE TABLE public.tags (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  tag TEXT NOT NULL,
  locale TEXT NOT NULL DEFAULT 'en',
  created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
  CONSTRAINT tags_tag_locale_unique UNIQUE (tag, locale)
);
```

**Fields:**
- `id`: Auto-incrementing primary key
- `tag`: Descriptive hint or tag text (unique per locale)
- `locale`: Language code (e.g., 'en', 'es')
- `created_at`: Timestamp when the tag was added

### 3. `public.word_tags`

Junction table linking words to their tags (many-to-many relationship).

```sql
CREATE TABLE public.word_tags (
  word_id BIGINT NOT NULL REFERENCES public.words(id) ON DELETE CASCADE,
  tag_id BIGINT NOT NULL REFERENCES public.tags(id) ON DELETE CASCADE,
  PRIMARY KEY (word_id, tag_id)
);
```

**Fields:**
- `word_id`: Foreign key to words table
- `tag_id`: Foreign key to tags table
- Composite primary key on (word_id, tag_id)

## View

### `public.words_with_tags`

A convenient view that returns words with their associated tags as an array.

```sql
CREATE VIEW public.words_with_tags AS
SELECT 
    w.id,
    w.word,
    w.difficulty_value,
    w.locale,
    w.created_at,
    ARRAY_AGG(t.tag ORDER BY t.tag) FILTER (WHERE t.tag IS NOT NULL) as tags
FROM public.words w
LEFT JOIN public.word_tags wt ON w.id = wt.word_id
LEFT JOIN public.tags t ON wt.tag_id = t.id
GROUP BY w.id, w.word, w.difficulty_value, w.locale, w.created_at;
```

**Usage in Flutter:**
```dart
final response = await supabase
    .from('words_with_tags')
    .select()
    .eq('locale', 'en');
```

## Indexes

Performance indexes are created for common query patterns:

```sql
CREATE INDEX idx_words_locale ON public.words(locale);
CREATE INDEX idx_words_difficulty ON public.words(difficulty_value);
CREATE INDEX idx_words_locale_difficulty ON public.words(locale, difficulty_value);
CREATE INDEX idx_tags_locale ON public.tags(locale);
CREATE INDEX idx_word_tags_word_id ON public.word_tags(word_id);
CREATE INDEX idx_word_tags_tag_id ON public.word_tags(tag_id);
```

## Row Level Security (RLS)

### Policies

All tables have RLS enabled with the following policies:

#### Read Access (SELECT)
- **Authenticated users** can read all words, tags, and word_tags
- Public read access for gameplay

```sql
-- Words
CREATE POLICY "Anyone can view words"
ON public.words FOR SELECT
TO authenticated
USING (true);

-- Tags
CREATE POLICY "Anyone can view tags"
ON public.tags FOR SELECT
TO authenticated
USING (true);

-- Word Tags
CREATE POLICY "Anyone can view word_tags"
ON public.word_tags FOR SELECT
TO authenticated
USING (true);
```

#### Write Access (INSERT/UPDATE/DELETE)
- **No policies** for regular users
- Only **service role** or **admin panel** can modify data
- This ensures data integrity and prevents abuse

## Data Migration

To populate the database with words from existing JSON files, you can create a script or use the Supabase admin panel.

### Example: Adding a Word with Tags

1. Insert the word:
```sql
INSERT INTO public.words (word, difficulty_value, locale)
VALUES ('elephant', 60, 'en')
RETURNING id;
```

2. Insert tags (if they don't exist):
```sql
INSERT INTO public.tags (tag, locale)
VALUES 
  ('large mammal', 'en'),
  ('has a trunk', 'en'),
  ('largest land animal', 'en')
ON CONFLICT (tag, locale) DO UPDATE SET tag = EXCLUDED.tag
RETURNING id;
```

3. Link word to tags:
```sql
INSERT INTO public.word_tags (word_id, tag_id)
VALUES 
  (1, 1),  -- elephant -> large mammal
  (1, 2),  -- elephant -> has a trunk
  (1, 3);  -- elephant -> largest land animal
```

## Difficulty Value Guidelines

When adding words, use these guidelines for assigning difficulty values:

- **1-20**: Very Easy (3-4 letters, common words)
  - Example: "cat", "dog", "sun"
  
- **21-40**: Easy (5-6 letters, simple words)
  - Example: "apple", "house", "water"
  
- **41-60**: Medium (7-8 letters, moderate complexity)
  - Example: "elephant", "computer", "mountain"
  
- **61-80**: Hard (9-10 letters, complex words)
  - Example: "basketball", "helicopter", "philosophy"
  
- **81-100**: Very Hard (11+ letters, rare/complex words)
  - Example: "extraordinary", "photosynthesis", "cryptocurrency"

## Querying Examples

### Get random word by difficulty range
```dart
final response = await supabase
    .from('words_with_tags')
    .select()
    .eq('locale', 'en')
    .gte('difficulty_value', 34)
    .lte('difficulty_value', 66)  // Medium
    .limit(50);
```

### Search words by tag
```dart
final response = await supabase
    .from('words_with_tags')
    .select()
    .eq('locale', 'es')
    .textSearch('tags', 'animal');
```

### Get word count by difficulty
```dart
final response = await supabase
    .from('words')
    .select('difficulty_value', const FetchOptions(count: CountOption.exact))
    .eq('locale', 'en')
    .gte('difficulty_value', 1)
    .lte('difficulty_value', 33);
```

## Notes

- Words are stored in uppercase by the game logic (accent removal applied)
- The Ñ/ñ character is preserved (not converted to N/n)
- Each word-locale combination must be unique
- Tags can be shared across multiple words
- Deleting a word cascades to word_tags entries
- Deleting a tag cascades to word_tags entries
